# Meeting English Trainer（ビジネス会議英語トレーニング）

システム開発・開発委託の会議を英語で進められるようになるための学習 PWA。
TOEIC 600点前後 → 実務で「聞く → 理解する → 質問する → 説明する → 調整・交渉する → 合意する」までを目標にする。

**公開URL：https://nknrmk8.github.io/english-learning-app/**

詳細な仕様は [SPEC.md](SPEC.md) を参照。

## 学習の流れ

1フレーズを **1画面にまとめて表示**する。順序の強制はしない。

### ① 聞いて理解する
「▶ 通しで聞く」ボタン1つで、**英 → 日 → 英 → 英 の4つが自動で連続再生**される。
途中のボタン操作は不要。もう一度押せば停止する。1つずつ個別の再生もできる。

| # | 内容 | 作り方 |
|---|---|---|
| 1 | 英語：ネイティブ寄りの話し方 | 端末で最も自然な音声（Natural / Neural / Online 系）を等倍で |
| 2 | 日本語：意味を確認 | 日本語音声で1回 |
| 3 | 英語：1語ずつはっきり | **発音は等倍のまま、語の間に区切りを入れて**1語ずつ聞き取れるように |
| 4 | 英語：普通の喋り言葉 | 1・3とは別の話者。再生のたびに声と抑揚を変え、人による違いに慣れる |

### ② 自分で話す
日本語を見て英語で発話。**話し終わったら「✅ 喋り終わりました」を押す**（自動では止まらないので、
考えながら話しても途中で切られない）。録音・音声認識のあと6軸評価＋改善英文が出る。

各セクションの右上に進み具合（`0 / 4 再生`・`✓ 通し再生済み`・`✓ 87点`）が出る。
力試しをしたいときは「🙈 英文を隠す」で英文をぼかせる。

## 主な機能

- **会議シナリオ 15本**（初級4・中級7・上級4）。目玉は「開発進捗確認とリリース判断」（11ステップ）
- **例文 156件**／10カテゴリ（開発委託・進捗・人員人月・予算・ライセンス・報告・売上・リリース・品質・運用保守）
- **発話評価 6軸**：発音／正確性／文法／語彙／流暢さ／会議表現としての自然さ（録音の終了はユーザーが押して決める）
- **復習**：苦手フレーズ・弱点単語・聞き取れなかった文・保存した表現・過去の録音
- **進捗**：今週の学習時間/レッスン数/発話回数/正答率、長期のカテゴリ別＆5分野（Listening / Speaking / Vocabulary / Fluency / Pronunciation）
- **ロールプレイ**：会話全体を最初から表示する台本形式。相手の発言は🔊で聞き、自分の番は模範例を見ながら
  声に出して練習（1ターンずつ採点）。「▶ 会話を通して聞く」で全体をリスニングもできる。台本6種＋シナリオ通し練習
- 端末内プロフィール（複数ユーザー切替・任意パスコード）、ダークモード、文字サイズ3段階

## スマホで使う

公開URLを開き、ホーム画面に追加する。

- Android (Chrome)：メニュー → 「ホーム画面に追加」
- iPhone (Safari)：共有 → 「ホーム画面に追加」

## ローカルで動かす

```
python -m http.server 8124
```

`http://localhost:8124` を開く。ビルド不要・依存ライブラリなし。

## 制約

- 音声合成・音声認識は端末のブラウザ機能（Web Speech API）を使用。**iOS Safari は音声認識に非対応**のため、STEP 3 は文字入力で採点する。
- 発話採点は端末内の簡易アルゴリズムによる参考値（外部AIに会議データを送らない方針のため）。
- 学習データ・録音は端末内（localStorage / IndexedDB）にのみ保存され、外部送信しない。
- 教材の会議データは実名・実組織名・実システム名をすべて仮称に置換している。
